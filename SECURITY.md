# Security policy

ZUNA AI is an early-stage project. Please do not file public issues containing secrets or sensitive user data.

## Reporting
Contact the repository owner privately through GitHub for potential security vulnerabilities. Do not disclose working exploits publicly before coordinated remediation.

## Public repository checklist
- Review current files and the entire Git history for credentials and tokens.
- Rotate any secret that has ever been committed, even if later deleted.
- Remove private customer records and proprietary assets.
- Use environment variables and a local .env file for development.
- Add secret scanning and branch protection before accepting contributions.

This document is guidance, not a certification that the repository has been security-audited.
