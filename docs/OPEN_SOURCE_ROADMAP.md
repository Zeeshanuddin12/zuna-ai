# ZUNA AI — Open Source Roadmap

ZUNA AI explores reusable AI-assisted real estate operations workflows. This repository is currently an early-stage public project; do not interpret its existence as proof of a deployed product, active users or qualifying open-source maintainer status.

## Proposed modules
1. Listing content generation with human review
2. Inquiry triage and lead qualification with consent
3. Owner and guest follow-up templates
4. Approval-gated social publishing
5. Audit logs, data minimization and role-based permissions

## Public/private boundary
Do not publish customer records, owner contacts, access credentials, booking details, API tokens, proprietary media or internal financial data. Use synthetic fixtures and examples only.

## Contribution principles
Contributions should solve real problems and include documentation or tests. Do not solicit fake stars, artificial PRs or fabricated usage metrics.
