# ZUNA AI contributor guidance

This public repository provides a local holiday-home listing draft tool and an attributed skill library.
Use synthetic examples only. Keep customer, guest, owner, unit and contact data outside Git.
Never store credentials. Never publish listings, change prices, issue refunds, or send messages without explicit human authorization.
The CLI only creates and approves local drafts; approval does not publish anything.
Run `python -m unittest discover -s tests -v` before changes.
